# 文档与知识的信息架构

## 核心模型

```text
组织 / 部门
  └─ 知识库（部门知识边界）
       ├─ 目录（分类 / 主题）
       ├─ 文档（原始资料，可下载、可重编译、可设访问策略）
       │    └─ 编译出的知识页（概念 / 实体 / 方法 / 决策 / 事实 / 文献）
       └─ 知识页（原子知识；保留来源文档、主张、冲突、版本）
```

- **文档是独立一等对象**：进入「文档中心」或知识库「文档」页，按部门、知识库、类型、状态筛选。
- **知识页必须可回溯到文档**：知识页右侧「来源」直接链接文档详情；文档详情列出它编译出的所有知识页，并按类型分组。
- **文档可管理**：标题、目录归档、原始文件下载、重新编译、访问策略（继承/受限/私有）。
- **知识片段可筛选**：知识库「知识页」页有类型 chips（概念/实体/方法/决策/比较/文献等）；每条知识页可打开编辑、校对、合并。

## 导航入口

| 入口 | 用途 |
| --- | --- |
| 文档中心 | 跨知识库查看所有部门文档；搜索/筛选/进入详情 |
| 知识库 → 文档 | 某部门知识库内的原始资料、覆盖统计、上传 |
| 文档详情 | 元数据、摘要、处理日志、编译出的知识页、来源链路 |
| 知识库 → 知识页 | 按类型筛选、编辑、校对、图谱 |
| 知识页右侧「来源」 | 返回具体文档详情 |

## 文档覆盖

- 文档列表显示“编译知识”数量；0 表示已入库但未生成知识页。
- 知识库文档页显示：文档总数、已编译、处理中、失败、无知识页。
- 文档详情按本体类型分组展示知识页，可过滤到单一类型。

## 权限

- 文档访问策略：`inherit`（跟随知识库）、`restricted`（仅所有者与显式共享）、`private`。
- 知识页继续使用页面级 ACL；查询与列表都先过滤再返回。
- 管理员可通过权限矩阵核对成员对知识库的有效角色。
