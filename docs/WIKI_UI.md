# Wiki 知识工作台

## 入口

```text
http://127.0.0.1:4520/#/knowledge
```

顶部导航改为：

```text
文档 · 知识 · 资料库 · 搜索 · 管理
```

开发版本不展示校对入口；`#/review` 会重定向到知识工作台。页面上的批准、退回、校对状态与校对按钮已移除。

## 布局

```text
左栏：知识库切换 / 页面搜索 / 类型导航 / 标签
中栏：知识首页或文章页
右栏：页面信息 / 反向链接 / 层级 / 本体属性 / 局部图谱 / 出链
```

## 类型

类型直接从本体读取并按页面数量展示：

- 文献
- 概念
- 实体
- 比较
- 方法
- 决策
- 笔记

点击类型会打开页面列表，并按类型过滤。

## 页面

文章页包含：

- 类型徽章与标签
- 标题、摘要、更新时间
- Markdown 正文与 `[[wikilink]]`
- 完整页面入口
- 反向链接 / 出链
- 上位与下位页面
- 本体属性
- 局部图谱

## 页面列表

默认收起，避免 500 页大列表遮挡首页。点击「页面列表」展开；点击类型、标签或搜索时自动展开。

## 说明

- 当前每库最多加载 500 页到前端；类型数量来自后端全量统计。
- 全库图谱：`#/graph?library=<slug>`。
- 校对流程仍在后端保留，仅开发 UI 隐藏。
