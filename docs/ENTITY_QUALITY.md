# 实体质量修复

## 问题

规则编译器使用宽松正则 `...公司|集团|电网`，把从句片段当成实体：

- 为新型电网
- 实现电网
- 该标准由南方电网
- 时期西宁电网
- 东北能源监管局通报电网
- 集团有限公司

## 修复

`server/src/knowledge/entities.ts` 增加：

1. 已知机构表与别名归一
   - 国家电网、南方电网、内蒙古电力集团、国网蒙东电力、五大发电集团、两网、两建、国家能源局、区域能源监管局等。
2. 严格校验 `isValidEntityName`
   - 拒绝虚词/动词/从句标记开头或出现在名称中。
   - 拒绝 `为、实现、由、该、也、在、对、推进、联合、论坛、集团有限公司` 等片段。
   - 拒绝标准编号作为实体。
   - 拒绝以数字开头的资产编号。
   - 只保留结构清晰的机构、设备与标准名称。
3. 已知机构优先
   - `国家电网有限公司` → `国家电网`
   - `中国华能集团有限公司` → `中国华能`
   - 重复名称归档，避免同一机构多个页面。
4. 规则抽取范围
   - 泛化公司名只从**标题**抽取，不再从正文起草单位列表批量生成。
   - 机构/设备从标题与正文抽取。
