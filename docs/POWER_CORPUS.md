## 导入方式

```bash
# 1. 抓取公开资料
node scripts/fetch-power-corpus.mjs

# 2. 创建资料库、分类节点并批量上传
node scripts/ingest-power-corpus.mjs
```

上传使用 `x-compile: rule` 走规则编译器，避免 200+ 篇资料同时触发本机 DSH 编译导致队列长时间阻塞；其中 16 篇为 DSH 编译，其余 190 篇为规则编译。需要更高质量的概念/实体抽取时，可在校对台对重点资料重新编译或逐篇触发 DSH。
