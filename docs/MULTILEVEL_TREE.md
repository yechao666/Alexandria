# 多级文档目录

## 结构

```text
部门
  └─ 知识库
      └─ 一级分类
          └─ 二级分类
              └─ 三级分类
                  └─ 文档
```

## 文档工作台

- `renderNode(node, depth)` 递归渲染任意深度。
- 每级节点独立折叠箭头。
- 父级计数聚合所有子目录文档数。
- 选择父目录时，文件列表包含子目录中的文档（通过 `data-node-path`）。
- 顶部提供目录筛选和「收起全部」。
- 未选中的知识库默认折叠；选中的知识库自动展开并滚动到可见区域。

## 电力行业标准库

510 条标准已从 9 个一级分类继续拆成二级目录，例如：

```text
发电与新能源
  ├─ 火电 68
  ├─ 水电 11
  ├─ 风电 2
  ├─ 光伏与光热 1
  ├─ 储能与氢能 29
  └─ 综合 38

配电与用电
  ├─ 配网 16
  ├─ 用电服务 7
  └─ 充电设施
```

## 新建子目录

资料库 → 目录 → 新建目录 → 选择父级，可继续创建任意层级。
