# 电力行业标准库导入记录

## 来源与范围

- 来源：全国标准信息公共服务平台（行业标准备案）
  - https://hbba.sacinfo.org.cn/
- 范围：行业分类「电力」的 **DL/T、NB/T** 等标准。
- 首批导入：**510 条**（现行 374、即将实施 136）。
- 平台当前可检索 4311 条电力行业标准；本批按发布时间优先导入，后续可增量导入。
- 每条标准保留：
  - 标准号、标准名称
  - 状态、发布日期、实施日期
  - 批准发布部门、技术归口
  - 中国标准分类号 / 国际标准分类号
  - 适用范围
  - 起草单位
  - 官方条目与在线预览链接

## 全文说明

- 本批录入的是**官方标准条目、适用范围和元数据**，不是标准全文。
- 行业标准全文版权归发布机构所有；每条文档保留官方在线预览链接，正式使用请以官方文本为准。
- 国家标准（GB/GB/T）全文公开系统当前不可访问；本批未包含 GB 标准全文。

## 脚本

```bash
# 抓取标准条目（默认 500 条，可用 STANDARDS_TARGET 调整）
STANDARDS_TARGET=500 node scripts/fetch-power-standards.mjs

# 创建「电力行业标准库」并入库
node scripts/ingest-power-standards.mjs
```
